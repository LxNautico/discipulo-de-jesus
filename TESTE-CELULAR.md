# Testar no celular

O jogo agora possui ajustes específicos de toque, navegação, campos, cartões e leitores em telas pequenas. É a mesma versão do computador, sem instalação de aplicativo.

1. Conecte celular e computador à mesma rede Wi-Fi.
2. Abra `iniciar-celular.cmd` no computador. É necessário ter Node.js instalado (já disponível neste computador).
3. Digite no navegador do celular um dos endereços “Celular” exibidos pelo servidor. Use o endereço do Wi-Fi; endereços de VPN ou adaptadores virtuais podem não funcionar no telefone.
4. Mantenha o computador ligado. Para encerrar, use Ctrl+C na janela do servidor.

Se o Windows solicitar acesso à rede, permita apenas na rede privada utilizada para o teste. Redes de convidados podem bloquear a comunicação entre aparelhos.

O servidor disponibiliza apenas index.html, JS e CSS referenciados pelo jogo. Não oferece listagem de pastas, documentos do projeto, arquivos-fonte JSON ou arquivos de outras pastas. As respostas usam no-store para facilitar testar as atualizações. O teste fica disponível apenas enquanto esse servidor está em execução; não é publicação em hospedagem.

O progresso do celular começa separado do computador, pois os dados ficam no navegador de cada aparelho. O leitor Bible.com e as fontes externas precisam de internet. Não há sincronização de contas nesta versão.

Roteiro rápido: abrir a jornada; pesquisar Abraão e abrir seu perfil; testar o seletor de versão e abrir/fechar o leitor; entrar em Dinheiro e generosidade e escrever uma reflexão; conferir Minhas conquistas. Depois gire o telefone e confira se o conteúdo continua utilizável.
